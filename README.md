# 🌊 Моя волна

Приложение для планирования и обмена приключениями с красивым интерфейсом и интуитивной навигацией.

## ✨ Особенности

- **Быстрый вход** - можно войти без заполнения формы
- **Поиск приключений** - интегрированный поиск в ленте
- **Интерактивные карты** - визуализация маршрутов
- **Социальные функции** - лайки, комментарии, группы
- **Адаптивный дизайн** - работает на всех устройствах
- **Красивые анимации** - плавные переходы и эффекты

## 🚀 Быстрый запуск

### Предварительные требования

- Docker и Docker Compose
- Python 3.10+ (для инициализации базы данных)

### Вариант 1: Автоматический запуск (Рекомендуется)

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository-url>
   cd meet
   ```

2. **Запустите приложение одной командой**
   ```bash
   ./start.sh
   ```

3. **Откройте браузер**
   - Frontend: http://localhost
   - Backend API: http://localhost:8000
   - API Docs: http://localhost:8000/docs
   - MinIO Console: http://localhost:9001

### Вариант 2: Ручной запуск

1. **Скопируйте файл конфигурации**
   ```bash
   cp env.example .env
   ```

2. **Запустите сервисы**
   ```bash
   docker-compose up --build -d
   ```

3. **Инициализируйте базу данных**
   ```bash
   python3 init_db.py
   ```

### Вариант 2: Локальная разработка

1. **Установите и запустите бэкенд**
   ```bash
   cd backend
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   uvicorn app.main:app --reload --port 8000
   ```

2. **В новом терминале запустите фронтенд**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Откройте браузер**
   - Перейдите по адресу: http://localhost:5173
   - Зарегистрируйтесь или войдите в систему

## 📱 Функциональность

### ✅ Реализованные возможности

- **Полноценная аутентификация** - регистрация и вход с JWT токенами
- **Личный профиль** - отображение информации пользователя и статистики
- **База данных** - SQLite с моделями пользователей, постов, комментариев и лайков
- **Загрузка в S3** - поддержка загрузки фотографий в AWS S3 (с fallback на локальное хранилище)
- **Лента постов** - просмотр всех постов с пагинацией и автоподгрузкой
- **Создание постов** - добавление новых постов с описанием и множественными фотографиями
- **Поиск** - поиск по названию и описанию постов
- **Лайки** - возможность ставить и убирать лайки постам
- **Комментарии** - добавление комментариев к постам с отображением автора
- **Адаптивный дизайн** - работает на всех устройствах
- **Темная тема** - переключение между светлой и темной темой с сохранением в localStorage
- **Docker контейнеризация** - готовые Docker контейнеры для развертывания
- **Автоматическая загрузка** - подгрузка новых постов при скролле

## ⚙️ Конфигурация

### Переменные окружения

Скопируйте `env.example` в `.env` и настройте:

```bash
# База данных (PostgreSQL)
DATABASE_URL=postgresql://mywave:mywave_password@postgres:5432/mywave

# JWT секрет (измените в продакшене!)
SECRET_KEY=your-secret-key-change-in-production

# S3/MinIO настройка
AWS_ACCESS_KEY_ID=minioadmin
AWS_SECRET_ACCESS_KEY=minioadmin123
AWS_REGION=us-east-1
S3_ENDPOINT_URL=http://minio:9000
S3_BUCKET=mywave-photos

# CORS настройки
CORS_ORIGINS=http://localhost:5173,http://localhost:5174,http://127.0.0.1:5173,http://127.0.0.1:5174

# Фронтенд
VITE_API_URL=http://localhost:8000
```

### Сервисы

- **PostgreSQL** - основная база данных
- **MinIO** - S3-совместимое хранилище для файлов
- **Backend** - FastAPI приложение
- **Frontend** - React приложение

## 🛠️ Доступные команды

### Разработка
- `npm run dev` - запуск сервера разработки
- `npm run build` - сборка для продакшена
- `npm run preview` - предварительный просмотр сборки

### Docker
- `docker-compose up --build` - запуск всех сервисов
- `docker-compose down` - остановка всех сервисов
- `docker-compose logs -f` - просмотр логов
