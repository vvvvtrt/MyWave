# 🌊 Моя волна

Приложение для планирования и обмена приключениями с красивым интерфейсом и интуитивной навигацией.

## ✨ Особенности

- **Быстрый вход** - можно войти без заполнения формы
- **Поиск приключений** - интегрированный поиск в ленте
- **Интерактивные карты** - визуализация маршрутов
- **Социальные функции** - лайки, комментарии, группы
- **Адаптивный дизайн** - работает на всех устройствах
- **Красивые анимации** - плавные переходы и эффекты

## 🚀 Быстрый запуск

### Предварительные требования

- Node.js (версия 16 или выше)
- npm или yarn
- Python 3.10+

### Установка и запуск

1. **Клонируйте репозиторий** (если нужно)
   ```bash
   git clone <repository-url>
   cd meet
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **(Опционально) Установите и запустите бэкенд на FastAPI**
   ```bash
   cd backend
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   uvicorn app.main:app --reload --port 8000
   ```

4. **Запустите приложение фронтенда в режиме разработки**
   ```bash
   npm run dev
   ```

5. **Откройте браузер**
   - Перейдите по адресу: http://localhost:5173
   - Нажмите кнопку "Войти" без заполнения полей
   - Наслаждайтесь приложением!

## 🛠️ Доступные команды

- `npm run dev` - запуск сервера разработки
- `npm run build` - сборка для продакшена
- `npm run preview` - предварительный просмотр сборки

## 📱 Использование

### Вход в систему
- Просто нажмите кнопку "Войти" или "Зарегистрироваться"
- Поля можно оставить пустыми

### Основные функции
- **Лента** - просмотр всех приключений
- **Мои путешествия** - ваши созданные приключения
- **Мои группы** - управление группами
- **Поиск** - поиск приключений по интересам

### Создание приключения
- Нажмите кнопку "Создать" в боковом меню
- Введите название приключения
- Приключение появится в разделе "Мои путешествия"

## 🎨 Технологии

- **React 18** - современный UI фреймворк
- **TypeScript** - типизированный JavaScript
- **Vite** - быстрый сборщик
- **Tailwind CSS** - утилитарный CSS фреймворк
- **Lucide React** - красивые иконки

## 🔧 Настройка

### Изменение порта
Если порт 5173 занят, Vite автоматически предложит другой порт.

### Кастомизация стилей
Все стили используют Tailwind CSS. Основные цвета:
- Оранжевый градиент: `from-orange-500 to-orange-600`
- Полупрозрачные фоны: `bg-white/15`
- Границы: `border-white/30`

## 🐛 Решение проблем

### Порт занят
```bash
# Убейте процесс на порту 5173
lsof -ti:5173 | xargs kill -9
```

### Ошибки зависимостей
```bash
# Очистите кэш и переустановите
rm -rf node_modules package-lock.json
npm install
```

### Проблемы с Tailwind CSS
Убедитесь, что файл `tailwind.config.js` содержит правильные пути:
```js
content: [
  "./index.html",
  "./src/**/*.{js,ts,jsx,tsx}",
]
```
